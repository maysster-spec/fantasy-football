10Commands

ff.bat is the only one you need most weeks. The others run from a terminal in the Scripts folder.

  1. ff.bateverything, in order

    Double-click it. Every step in order, then the checks; on the Tuesday task, ESPN’s projections too. It opens the week sheet only if the page changed.

  2. py wire.py --htmlthe wire and the week sheet

    What ff.bat runs in the middle. Use it when you only want the two pages.

  3. py lineup.py --htmlis anyone in my nine not playing

    Thursday evening and Sunday late morning, after the inactives.

  4. done "<some words>"tick something off THIS list

    Matches the words against the open items (exactly one, or it refuses), ticks it and rebuilds this page. `done --list` numbers them; `done --undo "..."` puts one back.

  5. py todo_page.pyrebuild this page

    No network, no ESPN. Reads Source\matt_todo.txt and rewrites this page and the sheet’s link.

  6. py check_kit.pyare the shipped files the ones I think

    Names, byte counts and hashes for the whole tree. Run it after anything of mine lands.

  7. py research\wk1\build_form.pyrefresh the week-by-week usage file

    ff.bat runs it at the top of every run. By hand only if the log says FORM FILE NOT REBUILT.

  8. py waivers.py --livepull this season’s transactions

    Needs your ESPN cookies. Writes waiver_report_2026.csv.

  9. py research\redteam\redteam_controls.pythe negative controls

    Every guard shown failing on the defect it was built for. Optional, and slow.

  10. py research\close_check.pywhat is actually still open

    Sorts every OPEN ledger row into candidate-closed / still-there against the shipping files. It names candidates; it never closes one.
