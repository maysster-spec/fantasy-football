## 1. IT CANNOT BE TESTED WITH ANYTHING IN THIS PROJECT

Same wall as the archetype question. "Committee", "unsettled backfield" and "the starter went
down" are not coded variables anywhere, and there are **no historical depth charts** — only 2026's.
The one proxy available, games played, is weak: among the 28 late RBs it gives rho +0.28,
**p=0.145** (n=28). Across all 109 RBs it reaches rho +0.227, p=0.018, but games-played is a
consequence of taking over, not a pre-draft signal. **`[UNDERPOWERED, NOT REFUTED]`.**

## 4. NOW IT IS A COLUMN — computed from data we actually have

`depth_map.py` now computes, per team, **RB1 minus RB2 projected points**, which is the only
