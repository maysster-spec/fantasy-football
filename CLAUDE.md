Fantasy football decision kit for Matt Mays (team JUG, ESPN league 21985, slot 8 of 12). Python scripts pull ESPN and nflverse data and build the HTML pages he reads each week (`WEEK_SHEET.html` above all).

## 1. Project rules (from 00_START_HERE.md and the directive)

**Matt does four things. Never do them for him:**
1. Anything that needs his ESPN session or runs on his machine.
2. Anything that WRITES to ESPN: lineup, claim, drop, trade, prerank. `espn_draft_injector_Gemini.py` POSTs to `lm-api-writes.fantasy.espn.com` with no dry run, and `weekend_check.py --inject` calls it. Never run either.
3. Money, or anything irreversible. A winning claim spends his waiver priority for the week, and a drop is permanent.
4. Supplying a file that exists only behind a login.

Outside those four, proceed without waiting for a go. Report the work as done, and state the claim in a form he can test so he can redirect.

**How to reply to Matt:**
- Open with a numbered do-this list (actions, changed rules, retractions), then a few short paragraphs. More than about 25 lines has failed.
- Give one recommendation, not a menu. Before you show any comparison, test each option. If an option is dead, say so in the first line.
- Check his ideas; he wants to be fact-checked. Challenge the substance of what he says, not how he says it.
- Do not use em dashes in anything written to him.
- A rendered page carries only the instruction and the plain number. Provenance (doc numbers, n, p-values) goes in `Source\*.md`.

**Numbers and claims:**
- Test a number before it goes into a recommendation. Never quote one from memory or from prose.
- Do not quote anything in the directive's DO-NOT-QUOTE table. For example, the no-drop failure rate is 16.2% on waiver claims, not 6.1%.
- Grep `Source\AUDIT_LEDGER.md` for `[OPEN]` rows before quoting.
- A generated page beats `00_START_HERE.md` on state, and a higher doc number beats a lower one.
- **The take contract (directive 0.1(h)):** any player take carries five things beside the name: vintage (`proj` or `2026, N games`), population and n, the man ahead, the standing rule plus the roster after the move, and the counterfactual.
- A drop may be named only if `MY_ROSTER.csv` was read this session and every candidate's keeper cost is stated next to him.
- When something cannot be tested, say which of three it is: TESTED (with population and n), NOT YET RUN (with the testable form), or BLOCKED (with the missing input).

**Freshness:**
- File names carry the date `ff.bat` last ran, not today. Check mtimes, and say it out loud when the data is stale.
- `injuries_2026.csv`, `depth_map.csv`, `inherit_2026.csv` and `sched_2026.csv` are never rebuilt automatically.
- `waiver_report_2026.csv` is rebuilt only by `py waivers.py --live`, which needs his cookies.

**League facts with no expiry:**
- Scoring: 0.5 PPR, 6-point passing TDs.
- Season: 14-week regular season; 6-team playoffs in weeks 15 to 17.
- Roster of 15: QB, RB, RB, WR, WR, TE, FLEX, D/ST, K, plus 6 bench and 3 IR slots.
- Position caps: QB 3, RB 6, WR 6, TE 3, D/ST 3, K 3.
- Keeper: George Pickens.
- Waivers run in standing order, not FAAB. Claims execute Thursday 03:00 to 06:00 ET, so place them Wednesday night.
- Put a drop on every claim.
- Count draft position in overall pick numbers, never rounds.

**Code rules (directive 0.4, 9):**
- Scripts must run on HIS Windows machine. Use the standard library plus pandas and numpy only, unless a dependency is confirmed there.
- Resolve every path against the script's own folder, not the shell's.
- Shell out to nothing without a fallback.
- Use raw strings for Windows paths.
- Keep CRLF line endings in `.bat` files.
- Archive to `2026\_archive\` before overwriting a canonical file. Keep one name with no version in it.
- Verify by content (hash), never by a tool's success result.
- Re-read shared files (`AUDIT_LEDGER.md`, `matt_todo.txt`, `OPEN_THREADS.md`) immediately before editing them; another model (Fable) writes to `Source\` too.
- **Do not change any script without being asked.**

**The weekly run:** `.\ff.bat` (five scheduled tasks plus double-click) rebuilds the pages. Its step order is in the `ff.bat` row below. `COMMANDS.html` at the 2026 folder root is the generated command list.

## 2. Running scripts in a cloud container

- ESPN hosts (`lm-api-reads`, `lm-api-writes`, `fantasy`, `site.api`, `www.espn.com`) are refused by this environment's network policy. Cookies are also blank in the uploaded copies, so every ESPN pull fails here.
- github.com/nflverse downloads are refused too. The nflverse files for 2021 to 2025 are already cached in `Scripts/research/_nflverse_cache/`.
- `pandas`, `numpy` and `scipy` must be pip-installed. `espn_api` and `browser_cookie3` are not installed.
- There is no PDF renderer and no `cmd.exe`, so `.bat` files cannot run.
- Many research scripts carry old sandbox paths (`/mnt/user-data/...`, `/home/claude/...`). Others expect nflverse files in their own folder rather than in the cache.
- The full per-script run results are in `SCRIPT_RUN_REPORT.md`.
